# ABC Аналіз по магазинах

Streamlit-додаток для ABC-аналітики валового прибутку по магазинах і номенклатурних групах.

## Структура репозиторію

```
├── app.py              ← головний файл Streamlit
├── shop_engine.py      ← рушій аналізу (парсинг, ABC, динаміка)
├── requirements.txt    ← залежності Python
└── README.md
```

## Деплой на Streamlit Community Cloud

1. Створіть новий **приватний** репозиторій на GitHub: `abc-shops`
2. Завантажте всі 4 файли
3. Зайдіть на [share.streamlit.io](https://share.streamlit.io) → **New app**
4. Repository: `ваш-нікнейм/abc-shops`, Main file: `app.py`
5. **Deploy!**

## Secrets (налаштувати у Streamlit Cloud → Settings → Secrets)

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
GITHUB_TOKEN = "github_pat_..."
GITHUB_REPO = "ваш-нікнейм/abc-shops"
```

## Вхідний файл

Файл Excel з такою структурою:
- Аркуш **`акції`**: ДАТА ПОЧАТКУ | ДАТА ЗАКІНЧЕННЯ | ТИП | АРТИКУЛ | НАЗВА
- Аркуші **`Місяць Рік р.`** (напр. `Квітень 2026 р.`): окремий аркуш на кожен місяць
  - Рядок 13: заголовки — Назва, Артикул, Група, Клас, Магазин1, Магазин2, ..., Підсумок
  - Рядок 16+: дані по SKU

## Можливості

- **ABC загальний** — всі SKU по всій мережі (без акційних місяців)
- **Групи товарів** — ABC по номенклатурних групах + графік
- **Магазини** — зведення по всіх магазинах: ВП, SKU, A/B/C
- **Місячна динаміка** — тренди по магазинах і групах
- **Збереження знімків** — щотижнева аналітика в `history_shops.json` на GitHub
- **AI-аналіз мережі** — тренди, рекомендації, прогноз
- **AI по кожному магазину** — оптимізація товарної матриці конкретного магазину

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```
